## Hi, I'm Darpan

Engineering intern, studying robotics and mechatronics.

I like the part of robotics where software meets something that moves: guidance and control, sensor fusion, and the tools you need to test them properly. Most of what I write is Python.

### Projects

**[TurtleRabbitSIM](https://github.com/AliveDPG/TurtleRabbitSIM)**
A test rig for the Space Teams PRO *Escape from Phobos* competition. It runs a shuttle controller from one command, throws harder debris fields at it than the competition does, batches runs, and reports how each one ended.

**[SpaceTeamsRepo](https://github.com/AliveDPG/SpaceTeamsRepo)**
The shuttle controller itself. Kalman-filter debris tracking that fuses radar and camera, closest-approach conflict checks along the planned path, and a burn, coast and trim guidance law. Pure numpy.

**[RemoteControl-](https://github.com/AliveDPG/RemoteControl-)**
A Kivy desktop remote for driving a robot over UDP, with on-screen buttons, WASD keyboard control and a multi-screen version.
